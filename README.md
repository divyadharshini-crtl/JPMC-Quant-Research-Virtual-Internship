# JPMC-Quant-Research-Virtual-Internship

"Quantitative Research project completing JPMC Virtual Experience. Developed a Logistic Regression model for default prediction and optimized FICO score bucketing using Dynamic Programming and Log-Likelihood maximization."

* **Task 4:** Optimized credit score quantization using Dynamic Programming.
